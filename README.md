## 1. Используемые технологии
* **Язык программирования:** Python 3.13
* **Графический интерфейс:** PySide6
* **База данных:** PostgreSQL (драйвер `psycopg2`, пул соединений)
* **Стилизация:** QSS (светлая и темная темы)

## 2. Назначение и основные функции
Приложение для автоматизации продаж магазина здорового питания.
* Авторизация по логину с разделением ролей (Администратор, Менеджер, Клиент).
* Каталог товаров с фото, ценами и остатками.
* Скидка 25% для товаров без заказов за месяц.
* Подсветка: зеленая цена, голубой фон для «Нет в наличии», перечеркнутая старая цена.
* Поиск, фильтрация, сортировка.
* Оформление заказов.

## 3. Порядок подготовки БД и запуска
1. Создайте БД `healthy_food` в PostgreSQL.
2. Выполните SQL-скрипт для создания таблиц.
3. Установите зависимости: `pip install -r requirements.txt`
4. В `database.py` укажите свой пароль.
5. Запустите: `python main.py`
