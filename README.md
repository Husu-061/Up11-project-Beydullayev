## 1. Используемые технологии
* **Язык программирования:** Python 3.13
* **Графический интерфейс:** PySide6
* **База данных:** PostgreSQL (драйвер `psycopg2`, пул соединений)
* **Стилизация:** QSS (светлая и темная темы)

## 2. Назначение и основные функции
Приложение представляет собой систему автоматизации продаж для магазина здорового питания. 
**Основные функции:**
* Авторизация пользователей по логину с разделением ролей (Администратор, Менеджер, Клиент).
* Просмотр каталога товаров с фото, ценами и остатками на складе.
* Автоматический расчет скидки 25% для товаров без заказов за последний месяц.
* Цветовая индикация: зеленая цена для выгодных предложений, голубой фон для товаров «Нет в наличии».
* Поиск, фильтрация по категориям/производителям и сортировка.
* Оформление заказов.
