# Мир здорового питания (ФормаДесерт)

**Автор:** Бейдуллаев Гусейн ЗИП-1-24

## Описание проекта
Приложение для автоматизации продаж магазина здорового питания. Система позволяет просматривать каталог товаров, фильтровать их по категориям и производителям, искать нужные продукты, а также оформлять заказы.

## Функционал
* **Авторизация:** Вход в систему по логину с разделением прав доступа (Администратор, Менеджер, Клиент).
* **Каталог товаров:** Отображение карточек с фото, категорией, ценой и остатком на складе.
* **Система скидок:** Автоматический расчет скидки 25% для товаров без заказов за последний месяц.
* **Подсветка:** 
  * Зеленый цвет для товаров со скидкой > 15%.
  * Голубой фон для товаров, которых нет в наличии.
  * Перечеркнутая старая цена и жирная новая.
* **Фильтрация и поиск:** Поиск по названию (без учета регистра), фильтр по категориям и производителям.
* **Сортировка:** По цене, наименованию и размеру скидки.
* **Темы оформления:** Светлая и темная темы (QSS).
* **Отказоустойчивость:** Обработка ошибок БД, кэширование изображений и заглушки для отсутствующих фото.

## Технологии
* Язык программирования: **Python 3.13**
* Графический интерфейс: **PySide6**
* База данных: **PostgreSQL** (psycopg2, пул соединений)
* Стилизация: QSS

## Запуск проекта
1. Склонируйте репозиторий.
2. Установите зависимости: `pip install -r requirements.txt`
3. Настройте подключение к БД в `database.py`.
4. Запустите приложение: `python main.py`
